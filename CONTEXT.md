# Scary Gary

Scary Gary is a harmless Windows desktop-creature prank whose on-screen behavior creates the illusion that one deeply unfortunate man lives in the computer.

## Language

**Gary**:
The fictional desktop creature whose unexplained behavior ranges from stupid to briefly terrifying.
_Avoid_: Malware, virus, assistant

**Gary Event**:
An extremely rare, short scare sequence in which normal Gary behavior stops, a frightening interruption occurs, and the desktop immediately returns to normal.
_Avoid_: Jumpscare, nightmare mode

**Scary Mode**:
The normal default experience in which Gary Events are eligible to occur.
_Avoid_: Optional horror mode, safety mode

**Garynap**:
A dormant period during which Gary disappears completely while remaining eligible to return later.
_Avoid_: Exit, quit, shutdown
